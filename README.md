# POLCA

This repo contains for POLCA, a method for decomposing changes in loss along arbitrary bases of the low-rank training subspace, from our ICLR 2026 paper [Hidden Breakthroughs in Language Model Training](https://arxiv.org/abs/2510.05064).

- `cluster_arithmetic_trajectories.py`: trajectory clustering code for the synthetic arithmetic setting
- `cluster_language_trajectories.py`: trajectory clustering code for the natural language setting
- `train_arithmetic_model.py`: training and POLCA computation code for the synthetic arithmetic setting
- `train_language_model.py`: training and POLCA computation code for the natural language setting
